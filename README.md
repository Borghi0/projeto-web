# 🌱 EcoLuz Comunitária

Projeto desenvolvido para a disciplina **Programação Web Front-End (2026_01)** da **UTFPR**, ministrada pela professora **Rosangela de Fátima Pereira Marquesone**.

O projeto tem como objetivo conscientizar a comunidade sobre o uso de **energia limpa, acessível e sustentável**, alinhado ao **ODS 7 da ONU — Energia Limpa e Acessível**.

---

## Sobre o Projeto

O **EcoLuz Comunitária** é uma aplicação web desenvolvida utilizando apenas **HTML5 e CSS3**, sem o uso de frameworks, conforme solicitado pela disciplina.

A proposta do site é apresentar informações sobre:
- eficiência energética;
- energia renovável;
- educação ambiental;
- soluções sustentáveis para comunidades locais.

Além disso, o sistema possui:
- página de cadastro;
- página de login;
- página principal com conteúdo informativo e visual.

---

## Objetivo do Projeto

O projeto busca:
- incentivar práticas sustentáveis;
- promover conscientização energética;
- apresentar soluções acessíveis para comunidades;
- aplicar os conhecimentos adquiridos em HTML e CSS.

## Funcionalidades

### Página de Cadastro
- formulário com múltiplos campos;
- botão de envio;
- direcionamento para login.

### Página de Login
- autenticação visual com e-mail e senha;
- acesso à página principal.

### Página Principal
- cabeçalho e rodapé;
- menu de navegação;
- imagens e ícones;
- seções informativas;
- links externos;
- layout responsivo;
- utilização de fontes externas.
